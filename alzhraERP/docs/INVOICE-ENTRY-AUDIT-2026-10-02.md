## كيف تُصحَّح الفاتورة بعد المراجعة

**الحالة 1 — العملة خاطئة (الفاتورة سعودية ووُسمت يمني):** يُصحَّح الوسم فقط، بلا أي أثر على ميزان المراجعة:
```sql
UPDATE public.invoices
   SET currency_code = 'SAR',
       exchange_rate = 1,
       total_document_amount = total_amount,
       subtotal_document_amount = subtotal
 WHERE invoice_number IN ('2-مبيع:xxxxx', '2-مبيع:yyyyy');
-- وينطبق نفس التصحيح على أسطر الدفتر المرتبطة (currency_code و foreign_amount)
```
**الحالة 2 — سعر الصرف خاطئ (العملة صحيحة):** يُصحَّح السعر **والمبلغ الأساسي**، لأن الأساس = المبلغ الأجنبي × السعر:
```sql
-- مثال 2-مبيع:14030: المبلغ الأجنبي 10,000 يمني، السعر الصحيح ≈ 0.002222
UPDATE public.invoices SET exchange_rate = 0.002222, total_amount = 22.22, subtotal = 22.22
 WHERE invoice_number = '2-مبيع:14030';
-- ثم تُصحَّح أسطر الدفتر (debit_amount/credit_amount = 22.22 و foreign_amount = 10,000)
```
⚠️ الحالة 2 **تُغيّر ميزان المراجعة وذمة العميل** ⇒ تحتاج موافقتك المسبقة على كل فاتورة.
