# تصحيح أسعار البنود إلى سعر المنتج في النظام — مُنفَّذ (2026-10-02)

## ما نُفِّذ

تصحيح البنود التي سعرها يزيد **×10 أو أكثر** عن سعر المنتج في النظام (`products.sale_price`)،
مع تعديل القيد المحاسبي المقابل وإعادة حساب رؤوس الفواتير.

| | النتيجة |
|---|---:|
| بنود صُحِّحت | **110 بنداً** |
| فواتير متأثرة | **106 فاتورة** |
| القيمة قبل | 405,725.52 ر.س |
| القيمة بعد | 5,571.91 ر.س |
| **التخفيض (أثر قائمة الدخل)** | **‎−400,153.61 ر.س** |

**أمثلة:**

| الفاتورة | الصنف | قبل | بعد |
|---|---|---:|---:|
| `2-مبيع:61889` | بوش مقص كامري 2007 | 10,000.00 | **15.00** |
| `2-مبيع:64254` | لعابة الامي افلون ×2 | 130,000.00 | **240.00** |
| `2-مبيع:62568` | كنويس الامي كرولا 2008 | 28,000.00 | **70.00** |
| `4-مر.مبيع:66` | براصات محرك كرولا | 19,000.00 | **68.80** |
| `2-مبيع:14030` | ربلات توازن هيلكس ×2 | 2,222.00 | **22.22** |

## ما شمله التصحيح (ثلاث طبقات متزامنة)

1. **البند** (`invoice_items`): `unit_price` = سعر المنتج، و`total` أُعيد حسابه
   وفق قيد النظام `total = quantity×unit_price − discount + tax`.
2. **رأس الفاتورة** (`invoices`): `subtotal` · `total_amount` · `total_document_amount`
   · `subtotal_document_amount` · و`paid_amount` للفواتير النقدية.
3. **القيد المحاسبي** (`journal_entry_lines`): خُفِّض **الطرفان معاً** بالمقدار نفسه
   (المدين والدائن) ⇒ التوازن محفوظ، و`foreign_amount` أُعيد حسابه بسعر صرف الفاتورة.
